# 🧠 Color Memory Game

A modern, eye-pleasing **Color Memory Game** built using pure HTML, CSS, and JavaScript. Test and train your memory skills by remembering and repeating an expanding sequence of flashing colors!

---

## ✨ Features

* **Sleek UI:** Dark theme styling featuring a frosted glass container (`glassmorphism`), smooth shadows, and custom Google typography (`Outfit`).
* **Visual Effects:** Glowing flashes on button triggers and a red vignette screen-shake animation when the game resets.
* **Pure Vanilla Stack:** Built without external libraries or frameworks—just clean HTML, CSS, and JS.
* **Responsive Layout:** Designed to look crisp and centered on desktop and mobile screens.

---

## 🎮 How to Play

1. **Start the Game:** Press any key on your keyboard to begin.
2. **Watch the Pattern:** The game will automatically flash a random color tile and update your current level.
3. **Repeat the Sequence:** Click the corresponding color pads in the exact order they flashed.
4. **Advance Levels:** Completing the correct sequence advances you to the next level with an additional step added to the pattern.
5. **Game Over:** Pressing the wrong sequence ends the game, displays your final score, and triggers a reset screen effect. Press any key to try again!
